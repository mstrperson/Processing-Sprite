What to do

Give your game a memory and a mind. It should track something, show it, and change what it does based on it.

  • Declare at least one variable at the top of your sketch that changes over time.
  • Show it on screen with text().
  • Use an if to branch the game into two different states — playing and game over.
  • Make the trigger and the game over screen yours. Do not leave the starter's "You Win!" if that is not what your game is about.

What to turn in

  1. Your sketch folder, zipped.
  2. Two screenshots: one of the game playing, one of your game over screen.
  3. Your answer to Show your thinking below.

To zip your sketch: Sketch → Show Sketch Folder, go up one level, then right-click the sketch folder and compress it.

Where am I?

Standard
Use if, changing variables (int score), and text() to make the program react and track state.
Getting StartedMy score or text will not show, or my if never triggers. Next step: declare your variables at the top (outside setup and draw) so every function can see them, and double-check your if condition.
Got It WorkingA variable changes during play, shows on screen with text(), and an if branches the game (playing vs. game over).
Made It Mine ⭐…and I changed what triggers the state change (a time limit, a different score), restyled the game-over screen, or added a second variable like lives.
Went Beyond…and I combined multiple conditions or variables so the game reacts in layered ways — the background shifts as score rises, lives count down, and so on.

⭐ Made It Mine is the goal for everyone. “Went Beyond” has no fixed list — the examples are only starting points. Going somewhere the lesson did not ask for is the whole idea.
