What you will be able to do

  • Store many objects in an ArrayList
  • Use a counting for loop to create a lot of things at once
  • Use a for-each loop to visit every thing in a list
  • Use random() to give a world variety

New words

ArrayList — a list that holds many objects of the same type. It grows as you add more
counting for loop — repeats a block a set number of times. Used to create things
for-each loop — visits every item already in a list, one at a time. Used to visit things
index — an item's position in a list. Lists start counting at 0, not 1

Before you code

💭 Think about it

How do you make your character move toward the mouse? Where exactly does that call go, and why there?

How it works

Why you need a list

Say you want twelve coins. You could write twelve variables: coin1, coin2, coin3… and then twelve new Blob(...) lines, and twelve move() calls, and twelve drawSprite() calls. That is thirty-six lines to manage, and if you want a thirteenth coin you write three more.

A list fixes that. Think of it as a bag — you keep stuffing things in, and the bag does not care how many.

Three things you do with a list
ArrayList<Blob> coins;                 // 1. declare it (what kind of bag)
coins = new ArrayList<Blob>();        // 2. create it (get an empty bag)
coins.add(new Blob(...));             // 3. add to it (put something in)

Two loops that both say "for"

Java uses the same word, for, for two loops that feel completely different. Keeping them straight is the real skill in this lesson.

The counting loop — for CREATING

This one counts. i starts at 0, and the loop repeats until i reaches 12. You use it in setup() to build your world.

  • int i = 0 — start counting at zero
  • i < 12 — keep going while i is under 12
  • i++ — add one to i each time around
"Do this 12 times"
for (int i = 0; i < 12; i++) {
  coins.add(new Blob(this, random(width), random(height), 12, color(255, 220, 50)));
}

The for-each loop — for VISITING

This one does not count. It just walks the list and hands you one item at a time. You use it in draw() to move and draw everything.

"For each coin c in the list, do this"
for (Blob c : coins) {
  c.move();
  c.drawSprite();
}

You cannot call a method on the whole bag

This is the mistake almost everyone makes at least once:

  • The bag is not a coin. You cannot ask the bag to draw itself — you have to reach in and ask each coin.
Wrong, then right
coins.drawSprite();     // WRONG - the list itself doesn't know how to draw

for (Blob c : coins) {  // RIGHT - draw each coin inside the list
  c.drawSprite();
}

Draw order decides what is on top

Whatever you draw last appears in front. That is why the player is drawn after the coins in the starter code — so your character is never hidden behind a coin.

This becomes a big deal in Lesson 8.

Build it step by step

  1. Open your Lesson 4 sketch. Your MyCharacter tab still does not change.
  2. At the top of the sketch, next to MyCharacter player;, declare the list: ArrayList<Blob> coins;
  3. In setup(), create the empty list: coins = new ArrayList<Blob>();
  4. Below that, add the counting loop from the starter code. Run it. Nothing shows up yet — you made the coins but never drew them.
  5. In draw(), above your player lines, add the for-each loop that moves and draws each coin. Run again. Now the world is full.
  6. Change the 12 in the counting loop to 40. Run. Then try 3. How many feels right?
  7. Change the coin color to something that fits your character's world.
  8. Move the player lines above the coin loop and run. Your character disappears behind the coins. Move them back. That is draw order.
  9. Add a mousePressed() that spawns a new coin wherever you click: coins.add(new Blob(this, mouseX, mouseY, 12, color(255, 220, 50)));

Starter code

This code runs exactly as it is. Get it running first, then start changing it.

Main sketch tab
// Lesson 5 - A World of Objects
import coxprogramming.processing.sprites.*;

MyCharacter player;
ArrayList<Blob> coins;

void setup() {
  size(800, 600);

  player = new MyCharacter(this, width/2, height/2);
  player.setVelocity(4, 0);

  coins = new ArrayList<Blob>();

  // Counting loop: add 12 coins at random positions
  for (int i = 0; i < 12; i++) {
    coins.add(new Blob(
      this,
      random(width),             // random x
      random(height),            // random y
      random(8, 20),             // random radius
      random(-2, 2),             // random horizontal speed
      random(-2, 2),             // random vertical speed
      color(255, 220, 50)        // gold
    ));
  }
}

void draw() {
  background(240);

  // For-each loop: visit every coin - move it and draw it
  for (Blob c : coins) {
    c.move();
    c.drawSprite();
  }

  player.followMouse();
  player.drawSprite();  // draw player last so it appears on top
}
Optional new tab — Cloud.pde
// A simple cloud sprite - draws itself as a cluster of white circles.
// Feel free to redesign this completely!
class Cloud extends Blob {

  Cloud(PApplet p, float x, float y, float speed) {
    super(p, x, y, 40, color(255));  // radius 40, white
    setVelocity(speed, 0);           // drift horizontally
  }

  void drawSprite() {
    noStroke();
    fill(250, 250, 255);
    ellipse(pos.x,      pos.y,      70, 45);
    ellipse(pos.x - 30, pos.y + 12, 50, 32);
    ellipse(pos.x + 32, pos.y + 12, 55, 32);
    fill(235, 238, 248);
    ellipse(pos.x - 12, pos.y - 16, 52, 38);
    ellipse(pos.x + 16, pos.y - 10, 44, 32);
  }
}

Make it yours

⭐ This is the part that matters most. Pick at least one and make it yours.

  • Change the number of things in your world, their speed, and their size.
  • Change their color and shape so they belong in your world — gems, fish, stars, bubbles, asteroids, hearts.
  • Add a second ArrayList of a different kind of thing. Enemies? Stars in the background? Two lists means two loops in draw().
  • Add a mousePressed() that spawns a new object wherever you click.
  • Make one list slow and drifting and another fast and darting — it makes the world feel layered.

Finished early? Write your own environment sprite class in a new tab — a Cloud, a Tree, a Star. It is the same extends Blob pattern from Lesson 2. Then make an ArrayList of those and fill your world with them. There is a Cloud example above to start from.
