Sounds

Add the click, the ding, and the music. It changes everything.

When to use this: Any time after Lesson 4. It pairs well with Bonus Lesson A (Images) as a two-part "make it real" session, or works on its own. Teach it whenever students ask "can we add sound?" — which they will.

New idea: Playing audio on game events   |   Builds on: Lesson 7 — collisions, so there is an event worth putting a sound on.

What you will be able to do

  • Install the Processing Sound library
  • Load a sound file from the data/ folder with SoundFile
  • Play a one-shot sound effect when something happens in your game
  • Loop background music underneath the whole sketch

New words

library — extra tools you add to Processing. You already use one: the SpriteGame library
SoundFile — a variable that holds a loaded sound. You call .play() or .loop() on it
.play() — plays the sound once, from the beginning
.loop() — plays the sound over and over, restarting when it reaches the end
.stop() — stops a sound that is playing
.amp(n) — sets the volume. 0.0 is silent, 1.0 is full

Before you code

💭 Think about it

What sounds do your favorite games use? Background music? Sound effects? Pick one sound and say what it tells the player.

How it works

First, install the Sound library

This is a one-time setup, and it is the step most likely to eat your time.

Sketch → Import Library → Add Library. Search for "Sound" and pick the one by The Processing Foundation. Install it, then restart Processing.

Then add this import at the top, next to the sprite one
import coxprogramming.processing.sprites.*;
import processing.sound.*;

Sound files go in data/, same as images

Sketch → Show Sketch Folder, then drag your audio into the data folder. Exactly like Bonus Lesson A.

MP3, WAV, OGG, and AIFF all work. WAV is the most reliable, especially for short effects.

Free sound: freesound.org, opengameart.org, zapsplat.com.

Three steps: declare, load, play

Same shape as everything else you have made. Declare it at the top, create it in setup(), use it when you need it.

The whole pattern
SoundFile collectSound;                                // 1. declare at the top

void setup() {
  collectSound = new SoundFile(this, "collect.wav");   // 2. load in setup
}

// 3. play it exactly where the event happens
if (player.collidesWith(c)) {
  coins.remove(i);
  score = score + 1;
  collectSound.play();
}

play() versus loop()

  • .play() starts the sound once. Calling it again while it is still going restarts it from the beginning. This is what you want for effects.
  • .loop() keeps the sound going forever until you call .stop(). This is what you want for music.
  • Music goes in setup() (start it once). Effects go wherever the event happens.

Where to put the sound is the real skill

The code for playing a sound is one line. Deciding where that line goes is the actual thinking, and it is the thing your teacher will ask you about.

A sound belongs at the exact moment the event occurs — inside the if that detects it, right next to the score change.

  • Collected something? Inside the if (player.collidesWith(...)) block.
  • Game over? Right where you set gameOver = true;.
  • Background music? Once, in setup(), with .loop().

Balancing the volume

Music at full volume drowns out your effects and the game becomes noise. Turn it down:

Music quieter than effects
bgMusic.amp(0.3);   // 30% volume
bgMusic.loop();

Build it step by step

  1. Install the Sound library: Sketch → Import Library → Add Library, search "Sound", choose the one by The Processing Foundation, install, then restart Processing.
  2. Find two sound files: one short effect (a ding, pop, coin, or beep — WAV is best) and optionally a music loop of about 30 seconds.
  3. Sketch → Show Sketch Folder and drag both into the data folder.
  4. Add import processing.sound.*; at the top of your sketch, under the sprites import.
  5. Declare SoundFile collectSound; at the top with your other variables.
  6. In setup(), load it: collectSound = new SoundFile(this, "collect.wav"); — using your filename.
  7. Find the if (player.collidesWith(c)) block in your playGame(). Add collectSound.play(); right after the score line.
  8. Run it and collect something. If you get a null pointer error, the file was not found — check the name and the folder.
  9. Add a second sound for game over, right where you set gameOver = true;
  10. Add background music: declare it, load it, then bgMusic.amp(0.3); and bgMusic.loop(); in setup(). Play it and adjust the volume until the balance feels right.

Starter code

This code runs exactly as it is. Get it running first, then start changing it.

Main sketch tab
// Bonus Lesson B - Sounds
// Requires: Sketch -> Import Library -> Add Library -> "Sound" (The Processing Foundation)
// Sound files go in your sketch's data/ folder (same place as images).
// Replace "collect.wav", "gameover.wav", and "music.mp3" with your own file names.

import coxprogramming.processing.sprites.*;
import processing.sound.*;

MyCharacter player;
ArrayList<Blob> coins;
int score = 0;
boolean gameOver = false;

SoundFile collectSound;   // plays when a coin is collected
SoundFile gameOverSound;  // plays when the game ends
SoundFile bgMusic;        // loops continuously in the background

void setup() {
  size(800, 600);

  // Load sounds from the data/ folder
  collectSound  = new SoundFile(this, "collect.wav");
  gameOverSound = new SoundFile(this, "gameover.wav");
  bgMusic       = new SoundFile(this, "music.mp3");

  bgMusic.loop();  // start background music immediately

  player = new MyCharacter(this, width/2, height/2);
  player.setVelocity(4, 0);

  coins = new ArrayList<Blob>();
  for (int i = 0; i < 10; i++) {
    coins.add(new Blob(
      this, random(width), random(height),
      random(8, 18), random(-2, 2), random(-2, 2),
      color(255, 220, 50)
    ));
  }
}

void draw() {
  background(240);

  if (!gameOver) {
    playGame();
  } else {
    showGameOver();
  }
}

void playGame() {
  for (int i = coins.size() - 1; i >= 0; i--) {
    Blob c = coins.get(i);
    c.move();
    c.drawSprite();

    if (player.collidesWith(c)) {
      coins.remove(i);
      score = score + 1;
      collectSound.play();  // <- sound on collection
    }
  }

  player.followMouse();
  player.drawSprite();

  if (coins.size() == 0) {
    gameOver = true;
    bgMusic.stop();          // <- stop music
    gameOverSound.play();    // <- sound on game over
  }

  fill(50);
  textSize(24);
  text("Score: " + score, 20, 36);
}

void showGameOver() {
  textAlign(CENTER, CENTER);
  fill(80, 180, 80);
  textSize(52);
  text("You Win!", width/2, height/2 - 20);
  textSize(22);
  fill(50);
  text("Score: " + score, width/2, height/2 + 26);
  textAlign(LEFT, TOP);
}

Make it yours

⭐ This is the part that matters most. Pick at least one and make it yours.

  • Add a sound for hitting a hazard — a hurt, a crash, a buzz.
  • Add a sound when you click or press a key.
  • Balance the music volume with bgMusic.amp(0.3); — 0.0 is silent, 1.0 is full.
  • Add a sound that plays at a score milestone: if (score == 10) { levelUpSound.play(); }
  • Choose sounds that actually fit your world. A cartoon boing in a space game is a choice — make sure it is one you meant.

Finished early? Fix the machine-gun problem. When collisions happen fast, .play() restarts constantly and it stutters. Guard it: if (!collectSound.isPlaying()) collectSound.play(); Then decide which version you actually prefer — sometimes the stutter is the right choice.
