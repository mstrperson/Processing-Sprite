What you will be able to do

  • Make a new tab and write your own sprite class using extends Blob

  • Use pos.x and pos.y to anchor every shape to your character's center
  • Explain that extends means "built on top of something that already exists"

New words

class — a blueprint for making a new kind of object
extends — means "my character is built on top of Blob." Everything a Blob can do, your character can do too
drawSprite() — the method you fill in to say what your character looks like
pos.x / pos.y — your character's current position. Use these to place every shape relative to its center
tab — a separate file inside your sketch. Big sketches get easier to read when each class lives in its own tab

How it works

Your character is a Blob with a new face

A plain Blob already knows how to do a lot: it has a position, it can move, it can wrap around the screen, and later it will detect collisions. What it does *not* have is a look you care about. It is just a circle.

So instead of building a character from scratch, you build one on top of Blob:

The one line that does the work
class MyCharacter extends Blob { ... }

What extends gives you

extends Blob is the whole deal in one word. Your character now gets everything Blob knows how to do, for free. You do not write any of it.

All you have to add is what it looks like. That is the drawSprite() method.

The handshake line

Inside your class there is a constructor, and inside that is a line starting with super:

  • super(...) is the handshake that connects your character to the library. Copy it exactly.
  • The 30 is your character's radius — an invisible circle used later for collisions. Change it so it roughly matches how big your art is.
  • The color there is a backup. You are going to draw over it anyway, so it barely matters.
Copy this exactly
MyCharacter(PApplet p, float x, float y) {
  super(p, x, y, 30, color(100, 180, 255));
}

pos.x and pos.y are your character's belly button

Here is the important idea. Do not draw your character at fixed numbers like ellipse(400, 300, 60, 60). If you do that, your character is nailed to one spot forever and will not move in Lesson 3.

Instead, measure every shape from pos.x and pos.y — the character's center.

  • Minus x moves a shape left. Plus x moves it right.
  • Minus y moves a shape up. Plus y moves it down. (Yes, up is minus. Screens are strange that way.)
Measuring from the center
ellipse(pos.x, pos.y, 60, 60);           // body: right at the center
ellipse(pos.x - 12, pos.y - 8, 16, 16);  // left eye:  12 left, 8 up
ellipse(pos.x + 12, pos.y - 8, 16, 16);  // right eye: 12 right, 8 up

Order matters when you draw

Shapes stack. Whatever you draw later sits on top of what you drew earlier. Draw the body first, then the eyes, then the pupils inside the eyes. If your eyes vanish, you probably drew the body last and painted right over them.

Build it step by step

  1. Open your sketch from Lesson 1 (or start a new one and save it as MyCharacter).
  2. Make a new tab: click the small arrow at the far right of the tab bar and choose New Tab. Name it MyCharacter — no .pde on the end, Processing adds that for you.
  3. Paste the MyCharacter.pde code below into that new tab.
  4. Go back to your first tab and paste in the main sketch code below.
  5. Press ▶ Run. You should see a friendly blue face in the middle of the window.
  6. Now start changing it. Change the body color first — find fill(100, 180, 255) above the body ellipse and put in your own numbers.
  7. Move an eye. Change pos.x - 12 to pos.x - 20 and run. Watch it slide.
  8. Add one new shape of your own — a hat, an ear, an antenna, a nose. Remember: measure it from pos.x and pos.y.
  9. If your character ends up much bigger or smaller than the starter, change the 30 in the super(...) line to match.

Starter code

This code runs exactly as it is. Get it running first, then start changing it.

New tab — MyCharacter.pde
/**
 * MyCharacter - this is YOUR character. Change everything!
 */
class MyCharacter extends Blob {

  /**
   * The constructor: called once when you create the character.
   * "super" connects your character to the Blob it's built on.
   * The radius (30) is the invisible collision circle - make it match your art.
   */
  MyCharacter(PApplet p, float x, float y) {
    super(p, x, y, 30, color(100, 180, 255));
  }

  /**
   * drawSprite: called every frame to draw your character on screen.
   * Use pos.x and pos.y as the center - all other shapes are measured from there.
   */
  void drawSprite() {
    // Body
    fill(100, 180, 255);
    noStroke();
    ellipse(pos.x, pos.y, 60, 60);

    // Eyes
    fill(255);
    ellipse(pos.x - 12, pos.y - 8, 16, 16);
    ellipse(pos.x + 12, pos.y - 8, 16, 16);
    fill(30);
    ellipse(pos.x - 12, pos.y - 8, 8, 8);
    ellipse(pos.x + 12, pos.y - 8, 8, 8);

    // Smile
    stroke(30);
    strokeWeight(2);
    noFill();
    arc(pos.x, pos.y + 5, 24, 18, 0, PI);
  }
}
Main sketch tab
// Lesson 2 - Draw Your Character
import coxprogramming.processing.sprites.*;

MyCharacter player;

void setup() {
  size(800, 600);
  player = new MyCharacter(this, width/2, height/2);
}

void draw() {
  background(240);
  player.drawSprite();
}

Make it yours

⭐ This is the part that matters most. Pick at least one and make it yours.

  • Change the body shape. rect(), triangle(), or several overlapping ellipse() calls all work.
  • Add hair, a hat, wings, antennae, a tail, ears, a beak, horns — anything.
  • Change every color using Tools → Color Selector.
  • Add detail: eyebrows (they change the whole mood), freckles, a nose, a mouth with teeth.
  • Give it an expression. Angry eyebrows are two short line() calls and they change everything.

Finished early? Make a second character class in another new tab — a sidekick, a pet, a rival. Same pattern, different art.
