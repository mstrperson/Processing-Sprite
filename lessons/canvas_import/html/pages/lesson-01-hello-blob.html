New words

sketch — a Processing program
setup() — the function Processing runs one time, right when your sketch starts
draw() — the function Processing runs over and over, about 60 times every second
object — a thing in your program that has its own information and knows how to do things
method — something an object knows how to do. You call it with a dot: myBlob.drawSprite()
RGB — the three numbers (Red, Green, Blue) that describe any color. Each one goes from 0 to 255

How it works

The two magic functions

Every Processing sketch is built out of two functions, and you will use them in every single lesson from here on.

setup() is like setting up an art table. It happens once, before anything else. You put out your paper and your paints, and then you are done setting up.

draw() is like drawing one page of a flipbook. Processing runs it again, and again, and again — roughly 60 times a second. Flip those pages fast enough and it looks like motion.

  • Something that happens one time? It goes in setup().
  • Something that has to keep happening? It goes in draw().

The import line

The very first line of your sketch is this:

The line that must be first
import coxprogramming.processing.sprites.*;

Making a Blob

A Blob is an object — a thing that lives in your program. To make one you fill in five pieces of information:

  • x and y are where the center of the blob sits. (0, 0) is the top-left corner of the window.
  • The radius is half the blob's width. A radius of 40 makes a circle 80 pixels across.
  • this means "this sketch." Copy it exactly and never change it.
Reading the Blob line
myBlob = new Blob(this, 400, 300, 40, color(255, 80, 80));
//                 |     |    |   |    |
//                 |     |    |   |    +-- what color it is
//                 |     |    |   +------- its radius (how big)
//                 |     |    +----------- its y position (up and down)
//                 |     +---------------- its x position (left and right)
//                 +---------------------- "this sketch" - never change it

Color is just three numbers

color(255, 80, 80) means: a lot of red, a little green, a little blue. That comes out as a warm pink-red.

Each number goes from 0 (none of that color) to 255 (as much as possible). color(0, 0, 0) is black. color(255, 255, 255) is white.

You do not have to guess. Open Tools → Color Selector, click around until you find a color you like, and read the R, G, and B numbers right off the panel.

Why background() is inside draw()

background(255) paints the whole window white. It is inside draw() because it has to happen on every single frame — it wipes the previous picture away so the next one starts clean.

Try taking it out later and see what happens. It is a good surprise.

Build it step by step

  1. Open Processing. You get an empty window with a big text area, a ▶ Run button, and a ■ Stop button.
  2. Save the sketch first: File → Save As, and name it HelloBlob.
  3. Type or paste in the starter code below. Getting it exactly right matters — one missing semicolon and it will not run.
  4. Press ▶ Run. A window should open with a red circle in the middle. Press ■ Stop to close it.
  5. Change the radius from 40 to 80 and run again. Then try 15. Watch what changes.
  6. Open Tools → Color Selector. Pick a color you like and read its R, G, and B numbers. Put those three numbers into color( , , ) and run.
  7. Move your blob: change the 400 and the 300 to put it somewhere else in the window.
  8. Change background(255) to background(0) and run. What happened, and why?

Starter code

This code runs exactly as it is. Get it running first, then start changing it.

Main sketch tab
// Lesson 1 - Hello, Blob!
import coxprogramming.processing.sprites.*;

Blob myBlob;

void setup() {
  size(800, 600);
  myBlob = new Blob(this, 400, 300, 40, color(255, 80, 80));
}

void draw() {
  background(255);       // white background erases the previous frame
  myBlob.drawSprite();   // draw the blob at its position
}

Make it yours

⭐ This is the part that matters most. Pick at least one and make it yours.

  • Change your blob's color using Tools → Color Selector. Pick one you actually like.
  • Change its size. Try a radius of 20, then 80. Which one feels right?
  • Move it somewhere else on the screen — a corner, the top, off to one side.
  • Change the background color to something other than white.
  • Add a second blob with its own color and its own spot. You will need a second variable, a second new Blob(...) in setup(), and a second drawSprite() in draw().

Finished early? Arrange four or five blobs into a small scene — a face, a snowman, a planet with moons, whatever you see in them.
