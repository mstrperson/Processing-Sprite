Saving and Handing In Your Work

Where your sketch lives, how to find it, and how it gets to Canvas.

Every lesson ends with the same job:  zip your sketch folder and upload it to the Assignment.  This page walks through it one click at a time.  The table at the bottom fixes a Finder window that looks wrong.  It also shows how to open a lesson's example, which every lesson from Lesson 2 on asks you to do.

On a Mac, right-click means hold down the Control key and click.  On a trackpad, you can also click with two fingers.

The short version

  1. In Processing, save:  File → Save.
  2. Open the folder:  Sketch → Show Sketch Folder.  A Finder window opens.
  3. Step out of the folder:  in Finder, Go → Enclosing Folder.
  4. Find your sketch's folder in the list (like HelloBlob), and click it once.
  5. Right-click it, and choose Compress "HelloBlob".
  6. A new file, HelloBlob.zip, appears next to the folder.  That's the one you hand in.
  7. On the Assignment, click Start Assignment, upload HelloBlob.zip, and click Submit Assignment.

Where your sketch is saved

A sketch is a folder.  When you save a sketch called HelloBlob, Processing makes a folder called HelloBlob, with a file called HelloBlob.pde inside it.  Every tab is another .pde file in the same folder, and Bonus A and B add a data folder inside it.  The folder is the whole sketch, so the folder is what you hand in.

Processing keeps every sketch together in your sketchbook.  On the school's Macs, that's the Processing folder inside Documents:

  • Documents › Processing › HelloBlob › HelloBlob.pde

The libraries folder in there is where SpriteGame is installed.  Leave it alone:  every lesson needs it.

Saving the first time:  File → Save As

A new sketch has a made-up name, like sketch_261101a, and lives somewhere temporary until you save it.  Save it before you type anything.

  1. Click File → Save As.  A Save box opens.
  2. Next to Save As, type the name, like HelloBlob.  Use letters and numbers, start with a letter, and leave out spaces.
  3. Look at Where.  It should say Processing.
  4. Click Save.

Where says something else?  Click it, and choose Processing from the list.  If it isn't in the list, click the small arrow button next to the name.  The box grows into a full window with a sidebar.  Click Documents in the sidebar, double-click Processing, and click Save.

Saving as you go

  • File → Save, or Command-S, saves the sketch where it already is.  Do it every time something works.
  • Before a big change, save a copy:  File → Save As, and add a number to the name, like MyGame2.  You keep working in the copy, and the old version stays put in its own folder.
  • To rename a sketch, use Save As.  The folder and the main .pde file need the same name, and renaming either one in Finder breaks the match.
  • To open it again:  File → Open Recent, or File → Sketchbook, in Processing.

Opening a lesson's example

Every lesson has an example:  its finished code, installed along with SpriteGame.  From Lesson 2 on, open it at the start of the lesson.  Run it to see where the lesson is headed, and keep it open, to compare with when your sketch does something strange.

  1. In Processing, click File → Examples.  A window opens with a list of folders.
  2. Find Contributed Libraries, and click the small arrow next to it.  Then open SpriteGame the same way, and then Lessons.
  3. Double-click the lesson you want, like Lesson03_BringItToLife.  It opens in a new window.
  4. Click ▶ Run.
  • Your work goes in your own sketch.  The example's character is a plain stand-in.  Before you type, check the name on the window's first tab.
  • To compare, put the two windows side by side, and read the same tab and function in both.  The example has more comments, so look past them to the code.
  • Typed in the example by accident?  Close its window, and click Don't Save.
  • Lesson 4 has two examples, _Mouse and _Keys, and Lesson 6 has one per day, _Day1 and _Day2.  The Bonus A and B examples are for reading:  they stop until they have your pictures or sounds.

Finding your sketch in Finder

Finder is the Mac's app for files and folders.  Its icon is the blue and white face at the left end of the Dock.  The surest way to find your sketch is to ask Processing, because it always knows where its own sketch is.

  1. With your sketch open in Processing, click Sketch → Show Sketch Folder (Command-K).  A Finder window opens inside your sketch's folder.
  2. To see the folder itself, step out of it:  Go → Enclosing Folder (Command-Up Arrow).
  3. Turn on the path bar:  View → Show Path Bar.  The bar along the bottom of the window shows where you are:  Documents › Processing › HelloBlob.

From Finder alone:  click Go → Documents, then double-click Processing.  Your sketches are the folders in the list.

Zipping your sketch folder

A zip is one file that holds a whole folder inside it.  Canvas takes one file per upload, so the folder goes in a zip.  On a Mac, making one is called Compress.

  1. In Processing, File → Save.  The zip holds your sketch as it was when you last saved.
  2. Sketch → Show Sketch Folder, then in Finder, Go → Enclosing Folder.
  3. Click your sketch's folder once, so it's the only thing highlighted.
  4. Right-click the folder (Control-click, or two fingers on the trackpad).
  5. Choose Compress "HelloBlob", with your sketch's name in the quotes.
  6. A new file appears next to the folder:  HelloBlob.zip.

✅ Check

The zip's name is your sketch's name, then .zip.  Got Archive.zip, HelloBlob.pde.zip, or HelloBlob 2.zip instead?  The table at the bottom of this page says what happened.

⚠️ Watch out

Leave the zip alone once it's made.  Double-clicking it unpacks a second copy of your folder and names it HelloBlob 2.  If that happens, drag HelloBlob 2, the one with the 2, to the Trash.

A screenshot of your sketch

Some Assignments ask for a picture of your sketch running, too.

  1. Run your sketch, so its window is open.
  2. Press Shift-Command-4.  The pointer turns into a small cross.
  3. Drag a box around the sketch window, and let go.

The picture is saved on your Desktop, named Screenshot with the date and time.  To get the whole window in one click:  Shift-Command-4, then the Space bar, then click the window.

Uploading to Canvas

  1. Open the lesson's Assignment, and click Start Assignment.
  2. Click Choose File.  Some Canvas pages call it Upload File, or let you drag the zip onto the page.
  3. A window opens that works like Finder.  Click Documents in its sidebar, double-click Processing, click your zip, and click Open.
  4. If the Assignment asks for a screenshot too, click Add Another File, then Choose File, click Desktop in the sidebar, and pick your screenshot.
  5. Click Submit Assignment.

✅ Check

Canvas says your work is submitted, and shows your zip's name.

Handing it in again

You can hand in every Assignment again, as many times as you like.  A zip is a snapshot of your sketch when you made it, so after a change you need a new zip.

  1. Save in Processing, and open the folder that holds your sketch folder, as above.
  2. Drag the old zip to the Trash, so the new one can take the same name.
  3. Compress the folder again.
  4. On the Assignment, click New Attempt (or Re-submit Assignment), and upload the new zip.

A Finder window remembers how it was last left, and sometimes it was left strange.  Click a Finder window first, so the menus at the top of the screen are Finder's.
